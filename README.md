# AI x finance experiments

Small, reproducible AI x finance experiments with honest results.

## Experiments

- [01: JEV-27B-VL on TSLA charts](01-jev-tsla-charts/README.md): can a zero-shot vision model predict the next five trading days from an unlabeled candlestick chart, and does it perform better on TSLA than NVDA?

Regenerated market data, chart inputs, model weights, and secrets are excluded from Git. Experiment results and selected sample figures are committed.
